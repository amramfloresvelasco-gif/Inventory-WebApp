# Inventory Web App

**Project:** Inventory Web App  
**Repository:** https://github.com/amramfloresvelasco-gif/Inventory-WebApp  
**Branch:** main  
**Status:** Phase 1 requirements and layout design; application not implemented  
**Established:** 2026-11-15

A separate, mobile-first inventory counting web application, independent of SPIRITS (formerly BMD Production Workbook V4) execution paths, but using its enriched reference data for Finished Goods, Raw Materials, and active Warehouses. Accuracy, reliable simultaneous submissions, and rapid scanning are primary requirements.

## Phases
- **Phase 1 — Inventory Entry:** current focus. Complete UI design first, then build and test fast, reliable counting.
- **Phase 2 — Reconciliation:** Blue vs Green counts; discrepancy resolution; comparison with Whiskey Systems (WS) official quantities. Detailed design deferred.

The old Inventory AppSheet/Apps Script code and screenshots are functional references **only**; do not copy an unreliable repair-dependent implementation wholesale.
